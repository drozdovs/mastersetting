Быстрый старт

  1. Вставьте карту памяти в кардридер.
  2. Нажмите «Сохранить с карты» и пройдите шаги мастера: карта → оператор и модель → название набора → готово.
  3. Проверьте предпросмотр: сколько файлов настроек найдено.
  4. Нажмите «Сохранить».

MasterSetting копирует только файлы настроек. Видео, фотографии и служебные индексы с карты не переносятся.

Если карта не нашлась сама, нажмите «Выбрать папку вручную» и укажите её папку. Системный диск и папку приложения выбрать нельзя — так настройки не попадут в неположенное место.

Сохранить с карты (карта → библиотека)

Каждое сохранение создаёт новую версию набора. Даже если вы сохраняете дважды в один день — предыдущая версия сохраняется.

Записать на карту (библиотека → карта)

  1. Шаг «Карта»: выберите носитель.
  2. Шаг «Что записать»: оператор, модель, набор и конкретную версию.
  3. Шаг «Изменения»: посмотрите, какие файлы будут созданы или заменены, — и только затем нажмите «Записать».

Безопасная запись

  • Сначала файл пишется во временный файл, затем проверяется по SHA-256.
  • Только потом заменяется целевой файл.
  • Если что-то пошло не так — выполняется откат к прежним файлам.
  • Обновляются только относящиеся к настройкам файлы; прочие данные карты не трогаются.

Не извлекайте карту во время записи. Приложение сообщит, когда карту можно безопасно вынуть, и предложит извлечь её одним нажатием.

Где взять пути карты

Приложение определяет папку настроек на карте автоматически. Если модель для вас новая и пути ещё не подтверждены, приложение честно сообщает об этом и предлагает импорт из папки с предварительным просмотром.

Чтобы закрепить точный набор файлов для новой модели, сохраните настройки прямо с камеры на карту и покажите этот набор приложению — пути фиксируются один раз и дальше используются автоматически.

Пары FX3 / FX3A

Пара — это две явно выбранные версии: одна для FX3, одна для FX3A. Пара может быть неполной (только FX3 или только FX3A). На экране «Пары» можно создать пару и сохранить её — это доступно всегда.

Парная ЗАПИСЬ включается только после подтверждения путей на реальных камерах. До этого момента в мастере записи выбор пары отключён, чтобы не записать настройки не туда.

Версии и надёжность

  • Версии никогда не перезаписываются автоматически.
  • У каждой версии — время, список файлов, размер и SHA-256.
  • После записи приложение заново перечитывает карту и сверяет содержимое.
  • Перед миграцией старого архива создаётся проверяемая резервная копия.

Библиотека: версии, экспорт, удаление

  • Экспорт позволяет получить копию конкретной версии (кнопка «Выгрузить версию…»), не меняя её в библиотеке.
  • Удаление пресета (кнопка «Удалить пресет…») необратимо и требует подтверждения с числом версий — случайно удалить не получится.
  • Пресет и версия выбираются в списке «Действия с пресетом / версией» под текстом библиотеки.

Администрирование

Вход в раздел администрирования защищён паролем администратора. Пароль хранится только в виде хеша; после нескольких неверных попыток вход временно блокируется.

  • Копии — «Создать копию» собирает снимок рабочих данных и, если настроен S3, отправляет его в хранилище. Копии хранятся 90 дней; в S3 можно поставить правило, чтобы старые версии снимков не занимали место бесконечно. В снимок попадают только рабочие данные и настройки — без видео с карты, временных файлов и программы.
  • Восстановление — перед заменой данных приложение делает страховочную копию.
  • Пробное восстановление — проверяет, что копия распаковывается, в отдельной папке, не трогая рабочие данные.
  • Отправить копии — досылает в S3 те снимки, что были отложены, пока не было интернета.
  • Хранилище S3 — адрес, регион, бакет и ключи. Ключи сохраняются в системном хранилище секретов и в резервную копию не попадают.
  • Канал обновлений — адрес https-манифеста и публичный ключ подписи. Приложение проверяет наличие новой версии само при интернете, но установку запускает администратор вручную.
  • Обновление — манифест принимается только с верной подписью; подделанную подпись приложение отклоняет.
  • Подготовить пакет — проверяет подпись и хеш файла, делает резервную копию данных и выкладывает проверенный установщик в папку обновлений. Запуск вы делаете сами, вручную — тихого автообновления нет. Журнал попыток виден в админ-панели.
  • Перенос 1.9 — переносит старый архив C:\setting в новую библиотеку, сначала создавая проверяемую копию.
  • Путь данных — где хранится рабочая библиотека. Путь настраивается, но каталог установки и системный диск выбрать нельзя.

Операторы выбирают имя без входа в систему. Поэтому личную конфиденциальность пресетов приложение гарантировать не может: любой за этим компьютером может открыть пресеты другого оператора. Разделение по именам — это удобство и порядок, а не защита.

Вопросы и ответы

Нужен ли интернет?

Нет. Повседневные операции работают полностью офлайн.

Копируется ли видео с карты?

Нет. Переносятся только файлы настроек.

Что будет со старым архивом C:\setting?

Он переносится отдельной операцией с резервной копией. Старые данные не удаляются, пока новый архив не проверен.

Где хранятся пароль и ключи?

В системном хранилище секретов (Keychain на macOS, DPAPI на Windows), а не в обычном конфиге и не в резервной копии.

Горячие клавиши F5 — сохранить с карты · F9 — записать на карту · F2 — библиотека · F3 — пары · F12 — инструкции · F4 — админ · F1 — справка. В мастере: Enter — главное действие шага, Alt+→ — дальше, Alt+← — назад, Esc — закрыть.
